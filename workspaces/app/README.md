# Boardie

Boardie is a mobile-friendly web application built with ReactJS and Typescript that enables board game enthusiasts to register their scores and track their progress over time. In addition, users can add friends and share their matches with them.

## Installation

To install Boardie, follow these steps:

1. Clone this repository to your local machine using git clone https://github.com/[username]/boardie.git
2. Install dependencies in the root folder by running pnpm install
3. Start the application by running npm start
4. Navigate to the server folder and install its dependencies by running pnpm install
5. Start the server by running npm start

Note that both the root and the server folder need to be executing for Boardie to work properly.

## Features

- Register scores for board games
- Add friends and share matches
- Mobile-friendly design
- Built with ReactJS and Typescript
